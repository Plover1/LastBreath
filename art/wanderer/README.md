# Комплект мандрівника душ

Автор мода: Siris102. Модель реалізована в SoulCloakRendering.java. approved-concept.png — погоджений художній концепт; preview.png — рендер фактичних запечених ігрових моделей, експортованих тестовим клієнтом (не скриншот світу). pose-*.json містять геометрію та UV поз анімації. armor-atlas.png — атлас 128×128. Іконки й тканина створені built-in imagegen; material-source.png та icon-source.png — оригінальні результати. Пакування атласу й зменшення іконок виконано nearest-neighbor, синій фрагмент узято з існуючої текстури тотема.

Матеріали: бежевий льон, коричнева шкіра, темна бірюзова тканина, старе золото. Поли рухаються при ходьбі, камінь зарядженого плаща трохи змінює масштаб. Це кубоїдна адаптація концепту, без симуляції тканини. Для використання потрібен мод на клієнті та сервері.
